Azure has provisioned a public IP for you. The chart's NOTES are generic and don't account for that.

1. Wait for the external IP. It takes a minute or two:

bash
kubectl get svc argocd-server -n argocd -w

Press Ctrl+C once EXTERNAL-IP changes from <pending> to an actual address.

2. Get the admin password:

bash
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath="{.data.password}" | base64 -d; echo

The trailing ; echo just adds a newline so the prompt doesn't run into the password.

3. Open it:

https://<EXTERNAL-IP>

Use https, not http. Your browser will warn about the certificate because ArgoCD ships with a self-signed one. Click through it. Log in as admin with the password from step 2.

That IP is publicly reachable by anyone. Fine for a lab, but change the admin password from the UI (User Info → Update Password) and then delete the initial secret:

bash
kubectl -n argocd delete secret argocd-initial-admin-secret

For your README, this is another good "lab shortcut vs production" callout: production would put ArgoCD behind an ingress with a real TLS certificate and SSO, plus a network restriction so the endpoint isn't open to the internet.
